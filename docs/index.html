Возможности

Всё, что нужно аналитику — без SQL-курсов и без облака.

Вопрос → SQL → ответ

LLM сам пишет SQL по естественному языку. Автоисправление галлюцинаций колонок, forward references и паттернов MAX/MIN.

Мультитабличные запросы

Автоматическое определение связей между таблицами и генерация JOIN — от простых срезов до сложных аналитических разрезов.

Голосовой интерфейс

Спрашивайте голосом и слушайте ответ: Whisper для распознавания, Edge TTS для озвучки. Всё локально.

Интерактивные дашборды

KPI-карточки с трендами, графики динамики, распределения — и в чате, и на дашборде. Экспорт диалога в DOCX.

Гибкий импорт

CSV, XLSX, DuckDB/SQLite и URL. Демо-данные в один клик, drag&drop с предпросмотром и автоопределением типов.

Инструкции ИИ

Настраивайте правила, рекомендации и контекст ассистента через UI — без правки промптов в коде.

RBAC и безопасность

Роли Admin/User, JWT, rate-limiting, безопасный SQL (только SELECT/WITH), bcrypt и гранулярные права.

Скорость

Многоуровневый кеш LLM и схем, предвычисленные манифесты колонок, стриминг ответов по WebSocket.

Как это работает

От файла до ответа — четыре шага, всё на вашей машине.

1

Загрузите данные

CSV, XLSX или база. Платформа профилирует колонки и строит манифест схемы.

2

Задайте вопрос

Текстом или голосом: «выручка по регионам за март», «топ менеджеров», «аномалии продаж».

3

ИИ строит SQL

Локальная LLM генерирует запрос, валидирует его и сама чинит типичные ошибки.

4

Получите инсайт

Таблица, график, KPI и саммари — сразу в чате. История сохраняется в сессиях.

Terminal — Offline Sales Analytics 
# macOS / Linux
git clone <url> sales-analytics
cd sales-analytics
chmod +x start.sh
./start.sh

Данные остаются у вас

Никаких облаков, API-ключей и телеметрии. LLM, распознавание речи и синтез голоса работают локально — продажи, клиенты и стратегия не покидают компьютер.

  • Локальный LLM-сервер Ollama и модель qwen2.5
  • Whisper STT и Edge TTS без сети
  • DuckDB на диске — ваши файлы, ваши правила
  • Desktop-сборка: всё в одном DMG, без Python и Node

Установка

Три шага до локальной аналитики. macOS, Linux и Windows.

1

Скачайте DMG

Возьмите сборку для Apple Silicon или Intel в Releases. Приложение автономно — Ollama и модель внутри.

2

Перетащите в Applications

Откройте DMG и установите приложение. При первом запуске: правый клик → Открыть.

3

Загрузите данные

Войдите, добавьте CSV/XLSX или демо-данные — и спросите что-нибудь у ассистента.

Рекомендуется: macOS 14+ / Ubuntu 22.04+, 16+ ГБ RAM, SSD 20+ ГБ. Для dev-режима — Python 3.9+ и Node 20+.

Или из исходников

Запасной путь, если DMG ещё не опубликован или нужен dev-режим.

macOS / Linux 
# клонировать репозиторий
git clone https://github.com/M3etis/Offline-Sales-Analytics.git
cd Offline-Sales-Analytics

# автоустановка Ollama, модели, venv и зависимостей
chmod +x start.sh
./start.sh

# остановка
./stop.sh
Windows · PowerShell 
git clone https://github.com/M3etis/Offline-Sales-Analytics.git
cd Offline-Sales-Analytics
powershell -ExecutionPolicy Bypass -File start.ps1

Скрипт поднимет бэкенд и фронтенд, откроет http://localhost:5173. Руководство по ручной установке и сборке Desktop (DMG) — в README.
